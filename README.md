# 橘子猫头 (Oyiso Plugin)

橘子猫头的多功能实用 WordPress 插件。

## 核心功能

### WooCommerce 增强
*   **变体拆分**：支持将 WooCommerce 可变产品一键拆分为独立的单品。支持复制父级与变体的多项数据（图片、价格、SKU、重量尺寸、库存等），并支持完美适配 Woodmart 主题附加设置及 SEOPress（SEO 标题和描述）。
*   **产品信息表**：为网站生成直观的商品信息前端表格，方便查看、分享、复制和导出站点商品数据。

### Elementor 扩展
*   **专属小部件**：为 Elementor 页面编辑器提供橘子猫头专属的小部件分类及组件扩展。

### 辅助与优化
*   **自定义代码**：支持在站点的 `<head>` 或 `<footer>` 区域便捷插入自定义代码（如统计代码、CSS样式、JS脚本等），无需修改主题源码。
*   **WP 优化**：提供多项 WordPress 核心功能及编辑器优化与调整。
*   **通知与备份**：集成网站消息通知（如 Telegram 提醒）与更新备份功能。

## 后台框架
*   本插件后台设置面板基于强大的 [Codestar Framework](https://github.com/Codestar/codestar-framework) 构建，提供现代化且直观的交互体验。
